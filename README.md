# ポスト収集 QRチェックポイント WebApp (PostCP)

郵便ポストの収集業務において、各ポストの収集チェックポイント用QRコードをスマートフォンから素早く検索・表示・スキャンするためのWebアプリケーションです。

---

## 🌟 主な機能と特徴

1. **高精細デジタルQRコード再生成（歪み・反射ゼロ・鮮明度100%）**
   - 既存の不鮮明なQRコード写真を画像解析し、内部の登録規格データ（`PST:01;CD1:管理番号;`）を完全特定。
   - ピンボケ・傾き・光の反射・雨粒が一切ない、**純白背景＋漆黒のベクターSVG QRコード**と、ポストプレート（管理番号・ポスト名・所在地）を完全新規再生成！
   - 携帯端末の画面をどれだけ拡大しても一切ボケず、業務用ハンディ端末で**一瞬で100%スキャン成功**します。
   - 画面上のタブで「✨ 高精細QR」と「📷 実物写真」をいつでもワンタップで切り替え可能。
2. **オフラインモード（電波の届かない地下・山間部でも動作）**
   - Service Workerによるキャッシュ技術を採用。
   - 画面上部の **「オフライン保存」** ボタンから、全ポストデータおよびQR画像をあらかじめ端末に一括ダウンロード可能。
   - 現場で圏外（電波ゼロ）になっても、**「📡 オフラインモード動作中」** バナーが表示され、通常通りポスト検索やQRコード表示・拡大が止まらずに行えます。
3. **モバイル＆現場作業に特化したUI/UX**
   - 大きな文字・大きなタップ領域で、現場での片手操作に最適化。
   - QRコードをタップすると全画面モーダルで大きくクリアに表示、さらにタップで拡大ズーム可能。
4. **巡回収集を加速する「前へ / 次へ」ナビゲーション**
   - QR表示画面の下部に「前のポスト」「次のポスト」ボタンを配置。
   - スマホ画面の**左右スワイプ操作**でも巡回順（No.1 → No.2 → No.3...）に次々切り替え可能。
5. **１区・２区のQRコード画像・ポスト登録機能**
   - 画面右上の **「＋ 登録」** ボタン、または1区・2区の画面にある **「＋ ポストを登録する」** ボタンから、簡単にポストを新規追加できます。
   - 区の選択、ポスト番号（自動採番）、ポスト名称を入力し、スマホのカメラで撮影または画像ファイルを選択して登録。
   - ローカル環境では `ポスト収集QRコード/` フォルダと `public/qr/` フォルダに自動保存され、Webブラウザ上（IndexedDB）にも即座に永続化されます。
   - 誤って登録したポストはQR表示画面のゴミ箱アイコンから削除可能です。
6. **QRコード画像の置き換え（現場での写真撮り直し対応）**
   - QR表示画面の上部「写真変更（カメラアイコン）」または画面下のリンクから、**現場でスマホで撮った新しい写真やファイルを選択して即座に差し替え可能**。
   - 差し替えた画像はブラウザ（IndexedDB）に自動永続化され、ローカル環境では実際の画像ファイルも自動更新されます。
   - 誤って変更した場合も「初期画像に戻す」ボタンでワンタップで復元可能。
   - 差し替え済みのポストには「差替済」バッジが表示されます。
7. **高速インクリメンタル検索**
   - ポスト名（「宮本」「八雲」「ローソン」など）やポスト番号（「1」「20」など）で瞬時に絞り込み。
   - ひらがな・カタカナ・全角半角の表記ゆれを自動吸収。
8. **1区・2区・3区のエリア切り替え**
   - 現在3区（全28件）を初期配置。
   - 1区・2区は画像を追加すれば自動的に反映される拡張構造。
9. **簡易共通ログイン認証**
   - 担当者5名で共有できる単一アカウント認証。
   - 一度ログインすれば1年間セッションを維持（現場での毎回の入力ストレスをゼロに）。
   - 環境変数でユーザー名・パスワードを自由に変更可能。
10. **PWA対応（ホーム画面追加）**
   - スマートフォンの「ホーム画面に追加」を行うことで、アプリアイコンから1タップでネイティブアプリ感覚で起動可能。

## 🚀 Vercel無料アカウントへのデプロイ手順

### 方法1: GitHub経由（推奨・一番簡単）

1. このプロジェクトのコードを GitHub のリポジトリに push します。
   ```bash
   git add .
   git commit -m "feat: ポスト収集WebAppの構築"
   git push origin main
   ```
2. [Vercel](https://vercel.com/) にアクセスし、無料アカウント（Hobbyプラン）でログインします。
3. **「Add New...」→「Project」** を選択し、本リポジトリを「Import」します。
4. **Environment Variables（環境変数）** の設定欄で以下を登録します（任意・デフォルトのままでも動作します）：
   - `APP_USERNAME`: ログインID（例: `post`）
   - `APP_PASSWORD`: パスワード（例: 任意のパスワード）
   - `AUTH_SECRET`: ランダムな英数字文字列
5. **「Deploy」** ボタンを押します。約1〜2分でURLが発行され、即座にスマートフォンから利用可能になります。

## 📁 １区・２区のQRコード画像を追加する方法

今後、1区や2区のQRコード画像を追加する際の手順です：

1. `ポスト収集QRコード/１区/` または `ポスト収集QRコード/２区/` フォルダに画像を配置します。
   - ファイル名形式: `番号. ポスト名.jpg` (例: `1. ○○郵便局前.jpg`, `2. △△公園横.jpg`)
2. ローカルで同期スクリプトを実行：
   ```bash
   npm run sync
   ```
   （`public/qr/` への配置と `src/data/posts.json` の更新が自動で行われます）
3. GitHubにコミット＆pushするだけで、Vercelが自動で再デプロイして反映されます。

```bash

npm install

npm run dev
# ブラウザで http://localhost:3000 を開きます

# 本番ビルドテスト

```
